# Palmira: Calles del Valle

Juego de conducción en mundo abierto ambientado en la Palmira real (toda el área urbana), Valle del Cauca (Colombia). Se juega en el navegador, en computador (teclado, ratón o mando) o en el celular (controles táctiles).

**Jugar:** https://chinaconsultantsgroup.github.io/palmira-calles-del-valle/

## Controles

| Computador | Acción |
|---|---|
| W A S D / flechas | Conducir o caminar |
| Espacio | Freno de mano |
| E | Subir/bajar, robar un vehículo, hablar, comprar, aceptar encargos |
| F | Bajarse del vehículo |
| H | Pito |
| C | Cámara |
| M | Mapa (toca un punto para marcar destino) |
| T | Teléfono |
| Q / R | Cambiar emisora de radio |
| Esc | Pausa |

En el celular aparecen un joystick y botones en pantalla.
